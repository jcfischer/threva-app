# Threva feature map

One file per part of the UI a person uses. Each says how to reach it, how to drive it, and what end state proves it works. A journey name means `bun run verify:ui <name>` covers it; "none yet" means add a journey before claiming the feature verified.

| Feature | File | Journey |
| --- | --- | --- |
| The Day: cards, timeline, footer | [day.md](day.md) | `day` |
| Everything: the outline and note pages | [everything.md](everything.md) | `everything` |
| The bar: write, ask, find | [bar.md](bar.md) | none yet |
| The desk: a Studio topic | [desk.md](desk.md) | none yet |
| Week: seven rolling days with dated outline links | [week.md](week.md) | `week` |
